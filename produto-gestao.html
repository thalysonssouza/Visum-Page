Como funciona

Você define quem vê o quê. Cada usuário acessa apenas o que é relevante para o seu papel.

Perfis de acesso por papel
Dono, supervisor, gerente e operador. Cada papel tem um escopo de dados e ações — sem precisar configurar manualmente cada usuário.
Processos padronizados por toda a rede
Um checklist criado na central é replicado automaticamente para todas as lojas. Padronização real, sem retrabalho.
Visão executiva consolidada
Compare qualquer loja com qualquer outra. Saiba imediatamente quais estão em risco e onde focar atenção e recursos.
Histórico de auditoria
Todo acesso, toda ação, todo dado alterado — registrado. Auditoria completa para quem precisa de rastreabilidade e compliance.

Perguntas frequentes

Consigo limitar o acesso de um gerente só a uma loja?
Sim. Em Configurações > Equipe, você define o escopo de cada usuário: loja específica, grupo de lojas ou toda a rede.
Posso criar perfis de permissão customizados?
Temos perfis padrão (Dono, Supervisor, Gerente, Operador) e nos planos Enterprise você pode criar perfis totalmente customizados.
Funciona para redes franqueadas?
Sim. O modelo de acesso do Visum é ideal para franquias: a franqueadora tem visão consolidada e cada franqueado vê apenas a sua(s) unidade(s).
Consigo ver o histórico de quem acessou o quê?
Sim. O log de auditoria fica disponível no painel administrativo, com data, horário e usuário para cada ação sensível.
